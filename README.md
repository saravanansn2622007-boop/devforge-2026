## Overview
**DevForge 2026** is a modern CineTech hackathon web application featuring 3D animations (Three.js / React Three Fiber), motion components (Framer Motion), interactive timelines, domains, prizes, and registrations.

- **Dates**: September 22 & 23, 2026
- **Duration**: 24-Hour Non-Stop Sprint
- **Total Prize Pool**: ₹8,000+
- **Platform**: React 19 + React Three Fiber + Framer Motion

---

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `build` folder.
