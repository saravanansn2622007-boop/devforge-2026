# DEVFORGE 2026 🎬⚡
### The Ultimate 24-Hour Kollywood CineTech Hackathon Platform

> **Where Tamil Cinema meets Cutting-Edge Engineering!**  
> Code like a Superstar, architect like a Director in **DEVFORGE 2026** — September 22 & 23, 2026.

---

## 🌟 Key Highlights & Features

- **🏆 Total Prize Pool**: ₹8,000 Spotlight Cash Rewards + CineTech Trophies & Incubator Access.
- **⏱️ Duration**: 24-Hour Non-Stop Sprint (160 Hackers & Creators).
- **🛡️ 4 Box-Office Tracks**:
  1. `Cybersecurity + Fullstack`
  2. `Mobile App`
  3. `Enterprise App`
  4. `AI / ML`
- **🌟 Interactive Superstars Arena**:
  - 3D parallax tilt & holographic foil card effects.
  - Bespoke vector artwork & animations for **Superstar Rajinikanth**, **Thalapathy Vijay**, **Chitti Robo 2.0**, **Kamal Haasan (Vikram/LCU)**, **Thala Ajith Kumar**, and **Suriya (Rolex / Chronos 24)**.
  - **Whistle Voting System**: Strictly 1 vote per Superstar ID per user with local persistence.
- **🎬 Kollywood Tech Punchlines (Easter Egg Generator)**:
  - Cinema clapperboard header with real-time `TAKE #` incrementation.
  - Dynamic hero spotlights, equalizer waveforms, and clipboard sharing.
- **👥 Multi-Step Registration (1 Lead + 3 Members)**:
  - Captures full participant data: **Name**, **Roll Number**, **Year**, **Department**, **Section**, and **Mail ID**.
  - Live FDFS VIP pass generator with barcode rendering.
  - Live registered crew roster modal desk.
- **🎵 Native Web Audio Synthesizer**:
  - Procedural sound generator for superstar whistles, clapper snaps, laser scans, and bass drops (Zero external audio asset dependencies).

## 🚀 Quick Start & Local Preview

Simply serve the repository using any local web server:

```bash
# Using Node.js (Built-in)
npx serve .

# Using Python 3
python -m http.server 3000
```

Open `http://localhost:3000` in your browser.
